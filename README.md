🎮 GetForce Shooter (Pygame):
GetForce Shooter is a simple 2D arcade-style shooting game built with Python and Pygame.
The player controls a green shooter at the bottom of the screen and must destroy incoming enemies while surviving as long as possible.

🚀 Features:
🔫 Smooth player movement (left/right controls)
💥 Automatic shooting system
👾 Randomly spawning enemies
📈 Dynamic difficulty (enemies spawn faster as score increases)
❤️ Health system with visual health bar
⚡ Power-ups:
Health Boost (+20 HP)
Rapid Fire (faster shooting)
🎯 Score tracking and level indicator
⚠️ Critical health warning
🕹️ Menu and Game Over screens

🎮 Controls:
Key	Action
⬅️ Left Arrow	Move Left
➡️ Right Arrow	Move Right
Space	Shoot
Any Key (Menu)	Start Game

🛠️ Technologies Used:
Python 3
Pygame library
Object-Oriented Programming (OOP)
Sprite groups & collision detection

🧠 Game Mechanics:
Enemies fall from the top of the screen.
Destroy enemies to gain +10 score.
If enemies reach the bottom, the game ends as your health reaches to 0 .
If enemies collide with you, you lose  health.
The game ends when health reaches 0.
Difficulty increases every 100 points.

📌 Project Purpose:
This project demonstrates:
Game loop structure
Sprite-based game design
Collision handling
Dynamic difficulty scaling
Clean class-based architecture in Pygame

📷 Preview:
You control the green shooter, eliminate red diamond enemies, collect power-ups, and survive as long as possible!
